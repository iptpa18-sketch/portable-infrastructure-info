Portable Infrastructure Backup

A private backup and recovery application for authorized users.

Application purpose

The application is intended to support encrypted backups, file version history, data recovery and storage management.

Google Drive integration

Google Drive is used to store and retrieve user-authorized encrypted backup data through Rclone and Restic.

Data protection

Backup contents are intended to be encrypted locally before upload. The application is not intended to sell user data or use it for advertising.
