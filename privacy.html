Privacy Policy

Effective date: November 24, 2026

1. Application purpose

Portable Infrastructure Backup is intended for private backup, version history, storage management and data recovery by authorized users.

2. Google user data

The application requests access to Google Drive to create, read, update, verify and restore user-authorized backup repositories.

3. Data usage

Google user data is used only for authorized backup, storage management and recovery operations. It is not sold, used for advertising or used to train artificial intelligence models.

4. Data storage and protection

The intended backup architecture uses Restic for local encryption before uploading backup contents and Rclone for Google Drive integration. Authentication credentials are stored locally and must be protected from unauthorized access.

5. Data sharing

Backup contents are not intended to be shared with third parties except as required to provide user-authorized storage services or comply with applicable law.

6. Data retention and deletion

Users control their backup retention policies and may delete backup repositories from their storage accounts or revoke application access through Google Account settings.

7. Google API compliance

The application is intended to comply with the Google API Services User Data Policy, including the Limited Use requirements.
